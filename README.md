⚽ FIFA World Cup Tournament Overview — Power BI Dashboard

📌 Project Overview
This project presents a Power BI dashboard that provides a high-level analytical overview of the FIFA World Cup tournaments held between 1930 and 2014.
The focus is on historical trends, country dominance, and tournament performance.


📊 Dashboard Highlights
Attendance trend by tournament year
Total goals scored per World Cup
Top goal-scoring countries (all-time)
World Cup winners summary
The dashboard is designed as a single-page tournament overview, following best practices for executive-level reporting.

🧠 Key Learnings
Normalizing home & away team data using Power Query
Writing efficient DAX measures
Understanding filter context vs row context
Designing insight-driven visuals instead of cluttered dashboards
